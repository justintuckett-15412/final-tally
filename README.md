# Final Tally

Family game night scorekeeper: Ticket to Ride, Carcassonne, Quacks, Hand and Foot, Canasta, Nerts, Hearts, Spades, Rage, Five Crowns, Skip-Bo, Gnoming A Round, Skyjo, Golf, Tripoley, darts, pool and a score pad for anything else.

Open the site on a phone and choose **Add to Home Screen** to install it. It works offline.
